FAQ-ассистент: демо-страница

Страница из урока: только оболочка для виджета в правом нижнем углу. Вся логика — в backend.

Запуск: uvicorn backend.app:app --host 127.0.0.1 --port 8301 с ALLOWED_ORIGINS=http://127.0.0.1:8080, затем python -m http.server 8080 --directory frontend и откройте http://127.0.0.1:8080.

На сайте ai.optimum-ltd.com тот же виджет ходит не напрямую, а через сам сайт (/api/chat).
